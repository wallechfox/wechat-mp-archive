# 微信公众号文章 + 评论导出工具（Web 版）

一个网页界面操作的工具，**扫码即可自动登录**，可视化拉取公众号**全部历史文章**和**评论/回复**，一键导出 Markdown / HTML / TXT / PDF，图片自动下载到本地，适合给公众号做离线归档备份。

## 功能特性

- **三种模式**：① 我的号（公众号后台，文章 + 完整评论）；② 别人的号（微信读书整号，仅正文）；③ 单篇下载（粘贴链接，免登录仅正文）。
- **扫码免复制**：微信读书、公众号后台均支持扫码登录，凭证自动填入。
- **全量历史文章**：从公众号后台「原创」列表分页拉取（`begin` 从 0 开始，翻到底），不丢第一页。
- **评论 + 回复**：抓取每篇文章的全部评论、点赞数、精选状态，以及作者回复。
- **短链自动导出**：模式 2 拉完列表后，自动逐篇提取短链并保存为 `output/日期公众号名公众号文章链接.txt`（`标题 + 短链` 逐行）；增量写入，中途出错不丢已提取部分。
- **四种导出格式**：Markdown / HTML / TXT / PDF，默认全选。
- **图片本地化**：正文图片自动下载到本地，导出后完全离线可看。
- **按日期归档**：输出文件夹与文件名都带日期，如 `公众号名_2026-10-19/2026-08-27_文章标题.md`。
- **文件布局可选**：每篇一个子文件夹，或平铺到同一目录。
- **选择性下载**：可全选/反选/勾选任意文章单独导出。
- **评论映射缓存**：本地缓存 `mid→comment_id` 映射，重复导出越用越快、越省请求。

## 三种模式

| 模式 | 数据源 | 登录方式 | 输出 |
|---|---|---|---|
| 模式 1：我的号 | 公众号后台「原创」列表 `cgi-bin/appmsgcopyright?action=orignal` + `misc/appmsgcomment` | 扫码登录后台（自动填 token/fingerprint/Cookie） | 文章 + 完整评论 |
| 模式 2：别人的号 | 微信读书 `weread.qq.com` 接口 | 扫码登录微信读书（自动填 Cookie） | 仅正文 + 短链 txt |
| 模式 3：单篇下载 | 文章短链 `mp.weixin.qq.com/s/xxx` | 无需登录 | 仅正文 |

> 模式 2 仅能拿到**正文**（微信读书不提供评论）；模式 3 免登录，适合零散链接的快速归档。抓取评论需要公众号后台的「留言管理」权限（即只能抓**自己**的公众号）。

## 安装

Python 3.8+（3.14 已实测）：

```bash
pip install -r requirements.txt

# 公众号后台扫码登录需要浏览器内核（约 150MB，首次运行前执行一次）
# 国内网络建议用镜像下载，速度快很多：
#   Windows (PowerShell)：
$env:PLAYWRIGHT_DOWNLOAD_HOST="https://npmmirror.com/mirrors/playwright/"
python -m playwright install chromium
#   Linux/macOS：
# PLAYWRIGHT_DOWNLOAD_HOST=https://npmmirror.com/mirrors/playwright/ python -m playwright install chromium
```

## 启动

```bash
python app.py
```

浏览器打开 **http://127.0.0.1:5000** 。

## 使用步骤

### 模式 1：导出自己的公众号（文章 + 完整评论）

1. 页面顶部选「模式 1 · 我的号」。
2. 点「扫码登录公众号后台」→ 弹出浏览器窗口 → 微信扫码确认 → 自动填入 `token` / `fingerprint` / Cookie，并识别当前公众号名。
3. 点「拉取文章列表」→ 右侧表格出现全部历史文章。
4. 勾选文章（或全选），选好格式与布局 → 点「导出」→ 日志实时显示进度。
5. 完成后在 `output/公众号名_日期/` 目录查看。

### 模式 2：导出别人的公众号（仅正文）

1. 页面顶部选「模式 2 · 别人的号」。
2. 填目标公众号名称，点「扫码登录微信读书」→ 自动填入 Cookie。
3. 点「拉取文章列表」→ 拉全历史文章后**自动提取短链**，保存为 `output/日期公众号名公众号文章链接.txt`。
4. 勾选文章导出正文（Markdown/HTML/TXT/PDF）。

### 模式 3：单篇 / 批量链接下载（免登录）

1. 页面顶部选「模式 3 · 单篇」。
2. 粘贴一个或多个 `mp.weixin.qq.com/s/xxx` 链接（每行一个）。
3. 点「下载」→ 逐篇抓正文导出。

## 常见问题

- **「原创」列表 vs 全部文章**：后台「原创」列表只含**声明了原创**的文章；若公众号还有未声明原创/转载的文章，需改用后台「内容管理 → 创作 → 发表记录」接口（本工具暂未内置，可提 Issue 补充）。
- **评论列表只有「未读」的？**：`get_unread_appmsg_comment` 返回有评论的文章，本工具用 `count=50` 一次拉全（实测上限 50），覆盖绝大多数据场景；已读评论若不在该列表则无法抓取。
- **评论报错 ret≠0**：后台凭证失效（时效较短），重新扫码登录公众号后台。
- **文章列表/正文报错**：检查 token 与后台 Cookie 是否有效；或改用微信读书回退方案（模式 2）。
- **PDF 转换失败**：需系统装有 Chrome 或 Edge，用其 headless 模式转 PDF，无需额外依赖。

## 技术要点

- 文章列表分页：`begin` 从 0 开始（不是 1），翻页条件看 `totalcount`；微信读书 `offset` 是列表偏移量（不是时间戳游标）。
- 评论定位：文章正文 HTML 的 `og:url` 是短链（不含 `mid`），真实 `mid` 在 HTML 的 JS 变量 `mid:"xxx"` 里；评论接口 `content_url` 才含 `mid`，两者靠 `mid` 精确对齐（标题不可靠，如 `V7.0` vs `V6.5`）。
- 评论映射 `mid→comment_id` 长期稳定，本地缓存避免重复遍历。
- 短链提取：微信读书列表接口不返回短链，需逐篇访问正文接口取 `og:url`；本工具用**流式读取**，读到 `og:url`（响应体前约 20KB）即断连，省去后续约 2.6MB 下载。
